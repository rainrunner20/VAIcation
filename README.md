# VAIcation — AI-assisted travel-planning prototype

This React + Vite app lets a user choose a location, trip length, budget, and group size. It includes an experimental Gemini itinerary generator, Google sign-in, Firebase/Firestore storage and a trip-details UI.

## Run locally

```powershell
git clone https://github.com/rainrunner20/VAIcation.git
cd VAIcation
npm ci
npm run dev
node --test tests/*.test.mjs
npm run build
```

## Current verified features

- Travel preference form, with validation for destination, 1–5 days, budget, and group size.
- Explicit error handling for failed itinerary generation or saving.
- Schema checking for generated JSON itineraries and stable loading states.
- Automated offline validation tests and a Vite build workflow.

## Limitations and configuration

This is a **prototype, not a live, verified booking service**. Hotel pricing, addresses and availability generated by an LLM must be independently checked.
The legacy browser-side Gemini integration reads a VITE_ environment variable. **Vite embeds those values into client JavaScript; do not put a valuable secret API key there or deploy that path publicly.** A server-side authenticated proxy with rate limits and quotas is required before a safe production AI release.
Google Places also uses a browser key, which must be restricted by referrer and API usage. The Firebase configuration references a project from an older tutorial and must be replaced with a project under your control and properly tested Firestore rules.
Live OAuth, Firestore permissions, Places results, model pricing, and a hosted deployment have **not** been verified in this milestone.
